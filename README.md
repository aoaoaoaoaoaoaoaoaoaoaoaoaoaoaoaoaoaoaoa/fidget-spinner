# Fidget Spinner

Fidget Spinner is Eternalist's local-first system of record for long-running
experimental work. It keeps the scientific spine narrow: a frontier scopes the
hill, hypotheses capture plausible KPI-moving ideas, and each experiment tests
exactly one owning hypothesis. Git retains implementation state; Spinner
retains experimental truth.

It is not a notebook, cloud service, task tracker, or parallel source archive.
The distribution contains one Rust CLI, a hardened stdio MCP server, a
server-rendered local navigator, and two Codex skills.

## Requirements

The supported 1.0 release target is x86_64 Linux. Building requires the pinned
Rust 1.97.1 toolchain, Cargo, Git, and `jq`. The installer can integrate with a
systemd user manager when one is available. SQLite is bundled.

Node.js 26 and Chromium are required only for the browser verification gate.

## Install

From a source checkout:

```bash
./scripts/install-local.sh
```

This builds a release binary, installs it at
`~/.local/bin/fidget-spinner-cli`, copies the bundled skills under
`~/.codex/skills/`, and installs the loopback navigator as
`fidget-spinner-ui.service`. Re-running the command upgrades those owned
artifacts. It refuses to replace unowned binary, skill, or service paths.
Binary publication is atomic. Existing Unix MCP sessions observe a stable
successor while idle and re-exec in place, preserving their stdio transport and
session state without a client restart.

To install the binary and skills without systemd integration:

```bash
FIDGET_SPINNER_INSTALL_SYSTEMD=0 ./scripts/install-local.sh
```

The optional first and second positional arguments are absolute replacements
for `~/.local` and `~/.codex/skills`. To remove installed programs while
preserving ledger state:

```bash
./scripts/install-local.sh --uninstall
```

## First Run

Initialize a project from anywhere inside its Git worktree:

```bash
fidget-spinner-cli init --project . --name my-project
fidget-spinner-cli project status --project .
```

Start an MCP session on standard input/output:

```bash
fidget-spinner-cli mcp serve --project .
```

An unbound MCP session begins with `system.health`, then `project.bind`. Walk
from `frontier.open`; use selector reads for detail. The bundled
[`fidget-spinner` skill](assets/codex-skills/fidget-spinner/SKILL.md) owns the
agent workflow, and [`frontier-loop`](assets/codex-skills/frontier-loop/SKILL.md)
adds the indefinite optimization loop.

The installed navigator listens at <http://127.0.0.1:8913/>. A foreground
instance is equally valid:

```bash
fidget-spinner-cli ui serve --bind 127.0.0.1:8913
```

The Results plot is Rust-rendered semantic SVG. Its series toggles, linked
datum inspection, horizontal drag zoom, dynamic units, and PNG clipboard
export require no TypeScript, frontend package registry, or frontend build step.

Exact CLI and MCP argument syntax is generated by `--help`, `tools/list`, and
`frontier.query.schema`; it is not duplicated here.

## State And Safety

Project stores live outside source trees under
`${XDG_STATE_HOME:-~/.local/state}/fidget-spinner/projects/`. A project path is
canonicalized and mapped to one self-describing SQLite store. Tests and
isolated deployments may set `FIDGET_SPINNER_STATE_HOME` to an absolute path;
Spinner appends its own `fidget-spinner/projects` hierarchy.

Non-scuffed experiment closure requires a clean Git worktree and records the
closing `HEAD`. Store upgrades from formats 9 through 19 to format 20 are
automatic and transactional. Back up `state.sqlite` with Spinner processes
stopped before a release upgrade. Older or newer unknown formats are rejected,
not guessed.

The navigator is an unauthenticated supervisor surface. It listens on loopback
by default, validates the loopback `Host`, and rejects cross-origin browser
mutations. Non-loopback binding requires `--allow-remote`; that flag grants no
authentication and is suitable only behind an access-controlled trusted
boundary. See [operations](docs/operations.md) for migration, recovery,
telemetry, service, and query limits.

## Verification

The canonical gates are non-mutating:

```bash
./check.py check
./check.py deep
```

`check` enforces the source policy, formatting, Clippy, and the complete Rust
test suite. `deep` adds rustdoc, a real Chromium journey over an isolated
hostile fixture, and an isolated install/uninstall trial. Canonicalization and
installation are explicit:

```bash
./check.py fix
./check.py install
```

To exercise cold and warm production-scale budgets against a copied store:

```bash
node scripts/ui-e2e.mjs --large-db /path/to/state.sqlite
```

The harness reflink-copies the database, drops its file cache before cold
navigations, chooses the largest non-archived frontier by closed-experiment
count, and never mutates the source store.

## Contract

Version 1.0 freezes the documented CLI grammar, MCP tool names and JSON shapes,
and SQLite compatibility policy for the 1.x line. Corrective validation and
additive fields or tools may ship within 1.x; removals and incompatible shape
changes require a major release. Navigator HTML/CSS and Rust crate internals are
not public APIs. The workspace crates remain `publish = false`; the supported
artifact is the tagged source-built CLI.

Domain policy lives in [metric and KPI governance](docs/metric-kpi-governance.md),
[supervisory tag governance](docs/supervisory-tag-governance.md), and the
[navigator specification](SPEC.md). Changes are recorded in
[the changelog](CHANGELOG.md). Fidget Spinner is available under the
[MIT License](LICENSE).
